Installation
Cloner le repository :
bash
git clone URL_DU_REPOSITORY

Installer les dépendances :
bash
composer install

Copier le fichier d'environnement :
bash
cp .env.example .env

Générer la clé :
bash
php artisan key:generate

Lancer les migrations :
bash
php artisan migrate

Démarrer le serveur :
bash
php artisan serve
